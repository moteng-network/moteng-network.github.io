# 发布与检查

本仓库由 GitHub Pages 从 `main` 分支根目录发布。`index.html` 是原官网的静态源文件；`.nojekyll` 关闭 Jekyll 处理，`CNAME` 记录官网域名。

修改后提交到主分支，检查 Pages 构建完成、域名 HTTPS 可访问，以及 `www` 跳转到主域名。不要在主分支放测试产物。

本地使用 `python3 -m http.server 8080`，分别以中文和英文浏览器语言打开；检查手动切换和刷新后的语言记忆。查看手机窄屏与桌面布局，确认邮件链接保留。

域名切换前备份旧解析和原站内容。先部署并验证 Pages，再配置自有域名和网站解析，等待 HTTPS 证书生效后开启 HTTPS 强制跳转。保留 GitHub 域名验证 TXT，邮件 MX / SPF 与其他子域名保持不变。原服务器文件保留，作为切换初期的回滚来源。
